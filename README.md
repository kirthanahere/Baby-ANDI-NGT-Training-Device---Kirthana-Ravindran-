# Baby ANDI — Infant NGT Training Mannequin (iDP)

A project to improve caregiver training for infant nasogastric tube (NGT) insertion using a higher-fidelity mannequin and real-time feedback.

## What this project does
- Provides a hands-on training mannequin for practising NGT insertion
- Uses sensor-based feedback to indicate correct/incorrect insertion progress
- Provides simple visual/audio cues to simulate patient response

## My role / contributions
- Research regarding current solutions 
- Consolidated user requirements with stakeholders
- Supported prototype testing and iteration
- Prepared documentation and presentation materials

## System overview (high-level)
- Inputs: Sensors placed along the insertion pathway
- Controller: Microcontroller (e.g., Arduino)
- Outputs: Visual indicator (LEDs) and audio cues (speaker)
